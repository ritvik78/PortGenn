# 🌐 Portfolio Generator

A simple and elegant **Portfolio Generator** built entirely using **HTML, CSS, and JavaScript** — no frameworks, no libraries!  
Just enter your details, and watch your personalized portfolio come to life instantly.

---

## 🚀 Features

- 🧑‍💼 **Dynamic Portfolio Generation** — Users can input their personal details, skills, and projects to auto-generate a portfolio webpage.  
- 🎨 **Fully Frontend (No Backend)** — Runs directly in the browser; no setup or server required.  
- ⚙️ **Live Preview** — See real-time updates as you fill in your information.  
- 💾 **Download Option** — Export your completed portfolio as an HTML file.  
- 📱 **Responsive Design** — Optimized for all devices using pure CSS.

---

## 🧰 Tech Stack

- **HTML5** — Structure and content  
- **CSS3** — Styling and responsiveness  
- **JavaScript (Vanilla)** — Logic, interactivity, and dynamic content rendering  

> No frameworks. No external dependencies. 100% native web technologies.

---

## 🖥️ How It Works

1. Open the `index.html` file in your browser.  
2. Fill out your personal and professional details — name, skills, projects, etc.  
3. Instantly preview your portfolio as you type.  
4. (Optional) Download or copy the generated portfolio file to share or host online.
